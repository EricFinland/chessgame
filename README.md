## 🎉 Features
- Play chess against a simple bot
- Every piece move triggers a random, funny animation
- Classic chessboard colors
- Modern, clean UI
- No backend required

## 🚀 Getting Started
1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. **Open in browser:**
   [http://localhost:5173](http://localhost:5173)

## 🗂️ File Structure
- `public/assets/pieces/` — Animation assets (future)
- `src/components/` — React components
- `src/animations/` — Animation lists per piece
- `src/utils/` — Chess logic and randomizer
