# Funny Chess Game

A simple React + TypeScript chess game with randomized, weird, and funny animations for each piece. Each chess piece has a set of 4-5 possible animations, randomly selected on move, capture, or promotion.

## Features
- Chessboard and pieces rendered in React
- Each piece type has its own animation list
- Animations are randomized per move
- Placeholder animation logic (replace with real assets for full effect)

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:5173](http://localhost:5173) in your browser

## File Structure
- `public/assets/pieces/` — Place animation assets here, organized by piece type
- `src/components/` — React components
- `src/animations/` — Animation lists per piece
- `src/utils/` — Chess logic and randomizer
